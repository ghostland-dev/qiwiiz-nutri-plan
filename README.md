# Qiwiiz Nutrition

Medical nutrition platform for patients and professionals.

## Features

- Meal planning and recipes
- Medical profile and nutrition dashboard
- Professional dashboard, shopping list and reports

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/qiwiiz-nutri-plan.git
cd qiwiiz-nutri-plan
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview

> The committed `.env` contains placeholder values only. Replace them with your own credentials locally.

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Fqiwiiz-nutri-plan)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_URL`
